## 💻 CPP

C++ fundamentals, split into lecture code and lab exercises.

| Folder | Contents |
|--------|----------|
| `lec_code/` | Examples written and discussed during lectures |
| `labs/` | Lab exercises, each solving a specific problem |

**Topics:** constants and input/output, functions, one- and two-dimensional arrays, structs, strings.

**Compile and run:**

```bash
g++ -std=c++11 file_name.cpp -o program
./program        # on Windows: program.exe
```

## 🧱 OOP

Three Python assignments that apply object-oriented programming concepts.

| # | Assignment | Concepts |
|---|------------|----------|
| 1 | **Digital Library Management System** | Dunder methods: `__init__`, `__str__`, `__len__`, `__call__`, `__del__` |
| 2 | **Vehicle System** | Encapsulation, hierarchical, multilevel and multiple inheritance, mixins |
| 3 | **Adventure Game Characters** | Abstract classes, polymorphism, composition, aggregation, class and static methods |

**Run:**

```bash
python file_name.py
```

## 📊 Pandas and NumPy

Data analysis and visualization with Python.

| Topic | What it covers |
|-------|----------------|
| **Data cleaning** | Missing values, duplicates, data types, preparing raw data |
| **Pandas** | Loading data, selecting, filtering, grouping, summarizing |
| **NumPy** | Arrays and numerical operations |
| **Matplotlib** | Line plots, bar charts and histograms with `pyplot` |

**Install the requirements:**

```bash
pip install pandas numpy matplotlib
```
